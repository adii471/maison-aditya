# ☕ MAISON ADITYA — Grand Cru Terroir & Reserve
### *Award-Winning Luxury Editorial Coffee Experience*

A cinematic, Awwwards-caliber coffee brand web experience built with **React 19**, **Vite**, **GSAP**, **ScrollTrigger**, and **Lenis Smooth Scroll**. Designed with high-contrast editorial typography, earthy volcanic palettes (espresso noir, burnt ember, raw alabaster, accent gold), and interactive molecular roasting simulations.

---

## 🌟 Highlights

- **🧈 Lenis Inertia Scroll**: Smooth inertia scrolling synchronized with GSAP ScrollTrigger ticker.
- **🎯 Magnetic Trailing Cursor**: Spring-physics cursor with contextual expansion and text labels (`CUPPING`, `TASTE`, `SELECT`, `ADD`).
- **📻 Web Audio Ambient Soundscape**: Built-in zero-dependency roastery audio engine with fireplace crackles, mountain wind, and dynamic equalizer bars in the navbar.
- **🎛️ Interactive Roasting Console**:
  - Live morphing 3D-styled coffee bean visualizer
  - Acoustic Maillard crack telemetry
  - SVG roast curve with interactive checkpoints
- **☕ The Golden Pour (9-Bar Hydrostatic Simulator)**: Real-time pressure slider adjusting flow rate, lipid emulsification, and crema bloom.
- **📋 Specialty Cupping Score & Brew Calculator**:
  - SCA 94+ Q-Grade radar breakdown
  - Dynamic dose calibration slider (1:16.2 ratio)
  - Gold confetti celebration upon selection
- **🛍️ Bespoke Taste Flight Drawer**: Slide-over reservation cart with free heirloom 24k gold tasting spoon unlock progress bar ($100 tier).
- **📜 The Aditya Manifesto**: Master roaster manifesto with animated number counters for direct-trade impact.
- **♿ Accessibility**: Reduced-motion toggle switch and fully responsive mobile drawer navigation.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Production Build
```bash
npm run build
```
